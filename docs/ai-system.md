# AI ARTISAN HUB — AI System

## Overview

AI ARTISAN HUB uses role-specific AI assistants designed for four different platform roles:

- Artisan
- Buyer
- Delivery Partner
- Administrator

The AI system is designed to retrieve authorized information, generate responses or drafts, and use controlled backend functions for consequential actions.

---

# AI Architecture

```text
User Request
     ↓
Identify Intent
     ↓
Check Role & Permissions
     ↓
Retrieve Authorized Data
     ↓
Generate Response / Draft
     ↓
Show Assumptions / Uncertainty
     ↓
Confirm Consequential Action
     ↓
Controlled Backend Function
     ↓
Audit Event When Required
