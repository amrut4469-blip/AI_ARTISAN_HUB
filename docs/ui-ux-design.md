# 💎 Premium UI, Motion & Animation

The UI should feel **premium, modern and fluid** without sacrificing speed.

## Motion Elements

| Element | Description |
|---|---|
| Animated splash | Logo reveal with subtle motion |
| Live background | Lightweight animated gradients / particles / craft-inspired motion |
| Glass-style cards | Restrained transparency and blur where the device allows |
| Micro-interactions | Like, save, follow, cart add, successful payment |
| Shared transition | Product card → product detail screen |
| Story progress | Smooth progress indicators |
| Skeleton loading | Placeholders instead of blank screens |
| Animated counters | For selected business metrics |
| Bottom navigation | Active-state animation |
| AI indicator | Calm idle motion and a clear processing state |
| Gestures | Pull-to-refresh and swipe with feedback |

## Animation Rules

1. Use animation to **explain state changes**, not just for decoration
2. Keep scrolling at a **high frame rate**
3. Avoid heavy effects on **low-end devices**
4. Prefer lightweight vector / Compose animation for repeated UI
5. Use image/video compression and **lazy loading**
6. Test live backgrounds against **battery and thermal** limits
7. Respect the user's **reduced-motion** preference
